项目简介
《暖石镇》是一款使用 Godot 4 和 C# 开发的2D卡牌RPG。游戏包含分支对话系统、卡牌回合制战斗、任务追踪以及多存档位持久化存储。这是我独立完成的个人项目，用于展示软件架构和系统设计能力。

核心系统
对话系统：支持条件分支、场景切换、传送后对话触发、选项回溯等功能的对话流程控制。

战斗系统：基于行动条的回合制卡牌战斗，包含手牌管理、敌人AI、卡牌效果系统（伤害/护盾/抽牌/增益/减益）。

任务系统：支持击杀/收集等多类型任务需求，实时进度追踪，完成任务后自动发放奖励。

存档系统：多存档位持久化存储，记录场景位置、条件状态、对话进度、收藏品、追随者等完整游戏状态。

技术栈
Godot 4 – 游戏引擎

C# – 主要编程语言

设计模式：

状态机 – 玩家控制器移动状态管理；战斗管理器阶段管理（空闲/玩家回合/敌人回合/过场/战斗结束）

策略模式 – 卡牌效果通过 I卡牌效果 接口实现多态，具体效果包括造成伤害、获得护盾、抽牌、观察弱点、二连击等

组合模式 – 任务卡片 UI 由多个子控件组合；卡牌 UI 拆分为外观/交互/动画/模式组件

观察者模式 – 使用 Godot 信号实现系统间解耦（任务更新、背包变化、对话事件、战斗结束等）

├── 任务系统/               # 任务系统（数据、UI、任务管理器）
├── 保存系统/               # 存档系统UI和逻辑
├── 对话系统/               # 对话系统（序列、选项、条件）
└── Scenes/                # 游戏场景（小镇、室内、战斗）
如何运行
使用 Godot 4.x 打开项目，运行主场景 StartMenu.tscn 即可。

开发背景
本项目是我在大二升大三的暑假期间独立完成的。我设计了全部系统架构并编写了所有核心逻辑。美术素材由AI辅助生成，使我能够将精力集中在游戏系统设计、软件架构和代码质量上。项目展示了我构建完整 RPG 游戏的能力，包括系统解耦、设计模式应用和可维护代码实践。
