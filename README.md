📖 项目简介
《暖石镇》是一款使用 Godot 4 和 C# 开发的 2D 卡牌 RPG。游戏包含分支对话、卡牌回合制战斗、任务追踪、多存档位持久化、玩家技能、装备、商店、回忆、跟随者等完整 RPG 系统。

这是我独立完成的个人项目，全部系统架构与核心逻辑均由本人手写，共 213 个脚本，代码量约 15000+ 行。美术素材由 AI 辅助生成，使我能将精力集中在软件架构、系统解耦和代码质量上。

项目旨在展示我构建完整 RPG 游戏的能力，包括设计模式应用、事件驱动架构、数据驱动设计和可维护代码实践。

✨ 核心亮点
完整 RPG 系统闭环：对话 → 战斗 → 任务 → 存档 → 商店 → 回忆 → 跟随者，所有系统相互联动。

数据驱动架构：对话序列、卡牌效果、任务需求、敌人技能、装备效果等均通过 Resource 配置，策划可独立编辑。

深度战斗系统：行动条驱动、玩家技能、Buff/装备、敌人 AI、阶段切换、失衡爆发、教程战斗。

健壮的存档体系：子资源分离存储、场景级存档位置、旧存档迁移、内存与磁盘同步。

现代化 UI 交互：四页签状态栏、三套卡组槽位编辑、完整键盘/手柄焦点导航、详情框与术语高亮。

工程化实践：对象池、事件解耦、延迟落盘、差量更新、自定义 Editor 工具。

🧩 核心系统
1. 对话系统
分支选项、条件分支、好感度/变量影响

场景切换、传送后对话触发、选项回溯

条件改变项：支持复合条件、关联任务、消耗道具、只执行一次

选项执行器：统一处理 12+ 种副作用（战斗、场景切换、道具奖励、任务接取、对话改变等）

对话历史回溯、场景展示 UI（含密码锁）、对话状态持久化

2. 卡牌战斗系统
行动条驱动回合制，速度值、冰缓、技能加速影响行动顺序

卡牌效果系统：策略模式 + 参数化配置，20+ 种效果（伤害、护盾、抽牌、二连击、施毒、燃烧、脆弱、虚弱、冰缓、沉默、净化、反弹、防御、弹反、观察弱点、引爆、条件加伤等）

玩家技能：三套技能（愤怒 / 认真 / 绝望），每套含被动触发 + 主动激活，与伤害结算链深度耦合

Buff 系统：毒、燃烧、再生、脆弱、虚弱、消散、架势、嘲讽、铁壁、狂暴、冰缓、沉默等，支持层数、叠加、永久、整回合

装备系统：勇气徽章、坚固盾牌、腐毒藤甲、锋利匕首、力量徽章、熔火壁垒等，提供力量、反弹、燃烧加成

敌人 AI：危险判断、防御优先、攻击选择、常驻技能、阶段切换、被动（血怒/孤军/群狼）

失衡爆发：弹反累积触发，排列面板选择卡牌顺序，消耗行动值爆发

教程战斗：预设抽牌序列，通过委托接管抽牌逻辑

战斗 UI：手牌拖拽、目标选择器、剩余卡组查看、战斗胜利界面、卡牌使用记录

3. 任务系统
支持击杀怪物 / 收集道具等多类型需求

实时进度追踪，NPC 头顶 ! / ? 标记联动

任务完成自动发放奖励（金币 / 卡牌 / 道具），并记录已完成任务 ID

任务面板 UI 与任务提示弹窗

4. 存档系统
7 个存档位，支持手动存档与自动存档

子资源分离架构：基础数据 / 场景数据 / 对话数据 / 进度数据 / 收藏数据

记录场景位置、条件状态、对话进度、已拾取道具、已购买商品、卡组槽位、任务列表、跟随者等

旧存档迁移：击杀进度从 ResourcePath 迁移到怪物 ID

内存状态与磁盘同步：重置内存状态到磁盘、清空当前状态

存档界面：双栏预览、保存成功提示、条件转场

5. 状态栏 UI
四页签：道具 / 角色 / 卡牌 / 设置

卡组编辑器：三套卡组槽位、卡池/卡组网格、卡组命名、灰化逻辑、左栏普通/强化预览

角色页：等级、经验、生命、速度、攻击加成、当前技能展示与切换

技能选择：三张技能卡，高亮、切换动画

完整键盘/手柄焦点导航：页签 ↔ 网格 ↔ 过滤器 ↔ 使用卡组按钮，手动重建邻居图

详情框：卡牌描述、术语解释、关键词高亮、滚动跟随

6. 其他系统
商店系统：商品购买、金币扣除、已购状态、购买记录写入存档

回忆系统：角色看法解锁、条件联动、界面展示

跟随者系统：动态跟随、动画切换、存档恢复

转场管理器：转场动画、摄像头动画、剧情序列、条件转场、场景缩放自动适配

一次性动画管理器：记录已触发动画，场景加载后恢复可见性

击杀统计管理器：按怪物 ID 统计击杀数，通知任务管理器

场景切换触发器：条件满足、消耗道具解锁、失败对话、强制后退

光源触发器：开灯/关灯对话，延迟触发

可燃烧物：玩家燃烧状态触发消失

可拾取道具：条件拾取、消耗所需道具、屏幕浮动提示

按键重绑定界面：输入映射保存/加载/恢复默认

音量控制面板：背景音乐/音效分离，自定义滑块样式
